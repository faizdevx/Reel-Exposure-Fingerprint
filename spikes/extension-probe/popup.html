REF M0 probe (throwaway)

Consent

While recording is on and you are on instagram.com Reels, this probe stores locally (in this browser only): Reel shortcodes, creator handle, caption, hashtags, timing, dwell, video state, and test frames from the visible Reel if "save frames" is on. It never reads cookies, passwords, tokens or network responses, never scrolls or clicks, and sends nothing to any server. You scroll by hand. Turn recording off or clear the log at any time.

Recording

After turning recording on, reload the Reels tab (F5) once so the host-permission capture path is tested without an activeTab grant.
